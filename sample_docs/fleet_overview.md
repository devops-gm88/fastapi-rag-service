# Acme Fleet telematics pilot

The pilot covers 120 vehicles across 3 depots.

The pilot started on 2026-09-01. The go-live date is 2026-11-15.

The project owner is the operations director. The fleet manager signs off each depot.

## Scope

- Live vehicle position every 15 minutes.
- Four sensor types: ignition, fuel level, odometer and door state.
- One alert inbox for the dispatch team.

## Out of scope

Driver behaviour scoring is out of scope for this phase.
